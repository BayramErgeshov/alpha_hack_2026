Общий контракт HTTP — [openapi.yaml](../openapi.yaml). В `examples/` лежат proxy Vite, синтетический запрос и сохранённые ответы локального API. Для прогона без расходов запускайте backend с `-NoLlm` и передавайте текст вместо URL.

Изменения HTTP-полей согласовываются с frontend; CSV и формата фрагментов — с командой данных; промптов и формата модельного ответа — с командой ИИ. Документы описывают текущий прототип; предложения развития отмечены отдельно.

> Актуальное описание решения — в корневом [README](../README.md). Документы этой папки, написанные до доработок (ARCHITECTURE, AI, FRONTEND, RUNBOOK), описывают исходный бэкенд; новые возможности — в [AGENT](AGENT.md), [FRONTEND_API](FRONTEND_API.md), [METRICS](METRICS.md), [SECURITY](SECURITY.md), [SCALING](SCALING.md), [DEPLOY](DEPLOY.md).
