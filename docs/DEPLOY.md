# Публикация на бесплатном сервере

Сервису нужно ~130 МБ памяти, поэтому подходит бесплатный тариф с 512 МБ.

## Публичная ссылка с компьютера (без аккаунтов, 5 минут)
Дважды щёлкните `start-public.cmd` (или `docker compose --profile public up --build -d`). Рядом с сервисом поднимается туннель Cloudflare, и скрипт печатает и открывает ссылку вида `https://<слова>.trycloudflare.com`. Ссылка работает с любого устройства, пока компьютер и Docker включены, и меняется после перезапуска. Ключ остаётся в контейнере сервиса, расход модели ограничен `ALFA_LLM_DAILY_TOKEN_LIMIT`. Остановить: `stop-demo.cmd`.

## Railway (без карты, пробный кредит на 30 дней)
New Project → Deploy from GitHub repo → этот репозиторий. Railway соберёт `Dockerfile`; в Variables задайте `ALFA_LLM_API_KEY` и `PORT=8080`, в Settings → Networking → Generate Domain с портом 8080.

## Hugging Face Spaces (Docker-спейсы требуют платный тариф PRO) (бесплатно, без банковской карты)
1. Зарегистрируйтесь на huggingface.co и создайте Space: SDK **Docker**, шаблон Blank, видимость Public.
2. Загрузите в Space два файла из `deploy/huggingface/`: `Dockerfile` и `README.md` (в заголовке README указан `app_port: 7860`). Dockerfile сам клонирует этот репозиторий, собирает сервис и прогоняет юнит-тесты.
3. Settings → Variables and secrets → **New secret** `ALFA_LLM_API_KEY` = ключ организаторов. В репозиторий ключ не попадает.
4. Через 5–8 минут сервис доступен по адресу вида `https://<user>-<space>.hf.space`. Чтобы подтянуть новые коммиты, нажмите Settings → Factory rebuild.
5. Бесплатный Space засыпает после 48 часов без посещений; перед демо откройте его заранее.

## Render (нужна привязка банковской карты даже для бесплатного тарифа)
1. Зарегистрируйтесь на render.com через GitHub и дайте доступ к репозиторию.
2. New + → Blueprint → выберите репозиторий: Render прочитает `render.yaml`.
3. В переменных окружения вставьте `ALFA_LLM_API_KEY` (ключ организаторов). В репозиторий ключ не коммитится.
4. Дождитесь сборки (в ней же прогоняются юнит-тесты). Сервис будет доступен по адресу вида `https://alfa-news-insights.onrender.com`.
5. Бесплатный сервис засыпает без запросов; первый запрос после паузы занимает ~1 минуту. Перед демо откройте страницу заранее.

## Любой сервер с Docker
```bash
git clone <репозиторий> && cd <папка>
cp .env.example .env   # вписать ALFA_LLM_API_KEY
docker compose up -d --build
```
По умолчанию порт опубликован только на 127.0.0.1; для внешнего доступа поставьте перед сервисом обратный прокси с HTTPS или измените публикацию порта в `docker-compose.yml`.

Для российских хостингов используйте `ALFA_LLM_BASE_URL=https://api.alfahack-gateway26.ru/v1`.

## Если включён `ALFA_API_TOKEN`
Токен требуется для всех `/api/v1/*`. Встроенный интерфейс токен не отправляет, поэтому для публичного демо токен не задаётся, а при необходимости закрытия доступа ставится обратный прокси с авторизацией.
