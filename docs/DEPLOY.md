# Публикация на бесплатном сервере

Сервису нужно ~130 МБ памяти, поэтому подходит бесплатный тариф с 512 МБ.

## Render (рекомендуется, 10 минут)
1. Зарегистрируйтесь на render.com через GitHub и дайте доступ к репозиторию.
2. New + → Blueprint → выберите репозиторий: Render прочитает `render.yaml`.
3. В переменных окружения вставьте `ALFA_LLM_API_KEY` (ключ организаторов). В репозиторий ключ не коммитится.
4. Дождитесь сборки (в ней же прогоняются юнит-тесты). Сервис будет доступен по адресу вида `https://alfa-news-insights.onrender.com`.
5. Бесплатный сервис засыпает без запросов; первый запрос после паузы занимает ~1 минуту. Перед демо откройте страницу заранее.

## Любой сервер с Docker
```bash
git clone <репозиторий> && cd <папка>
cp .env.example .env   # вписать ALFA_LLM_API_KEY
docker compose up -d --build
```
По умолчанию порт опубликован только на 127.0.0.1; для внешнего доступа поставьте перед сервисом обратный прокси с HTTPS или измените публикацию порта в `docker-compose.yml`.

Для российских хостингов используйте `ALFA_LLM_BASE_URL=https://api.alfahack-gateway26.ru/v1`.

## Если включён `ALFA_API_TOKEN`
Токен требуется для всех `/api/v1/*`. Встроенный интерфейс токен не отправляет, поэтому для публичного демо токен не задаётся, а при необходимости закрытия доступа ставится обратный прокси с авторизацией.
