Карта влияния и сценарии

Фронт работает без сборки и внешних JavaScript-зависимостей. Каталог ui раздаётся существующим бэкендом через ALFA_STATIC_DIR. API, серверный код и настройки не изменены.

index.html — структура экранов и доступные элементы управления.
app.css — общие стили утверждённого макета.
frontend.css — адаптация для данных API, мобильного экрана и состояний приложения.
app.js — компании, роли, лента, карта, запрос разбора, вкладки, калькулятор.
insight.js — факты, выводы, источники, ход агента, вопросы и оценка.
core.js — чистые функции расчёта, проверки URL и разделения ленты на страницы.
assets — локальный шрифт Golos Text с лицензией OFL.

Маршруты: #map (основной экран), #scenarios (калькулятор).
Компания выбирается из GET /api/v1/clients; при первом запуске используется первая доступная. Роль по умолчанию cfo, если она доступна. Выборы компании и роли изменяют GET /companies/{id}/feed. Все полученные события доступны по страницам из трёх элементов.

Выбор события показывает контекст из ленты, без вызова модели. Кнопка «Получить разбор» отправляет прежний POST /insights. При смене компании, роли или события старый разбор сбрасывается, запоздавшие ответы игнорируются. Вопросы и оценка используют прежние маршруты /questions и /feedback. Ссылки на внутренние источники раскрывают документ/страницу в списке источников. Позиция банка отображается только при наличии A-источника в ответе.

Калькулятор не предсказывает курс и не читает значения из новости. Начальные сумма и курсы обозначены как пример. Пользователь задаёт сумму, валюту, базовый и сценарный курс. Результат вычисляется локально; одинаковая шкала высот столбцов, валидация, положительная/отрицательная разница. Изменение валюты меняет единицу контракта, но не подставляет рыночный курс. Поля сохраняются при переключении вкладок в пределах открытой страницы.

Проверка чистой логики: node --test ui/tests/core.test.cjs
Внешний тестовый стенд для проверки UI не входит в приложение. В production нет фикстур, тестовых ответов, ключей или автоматического вызова моделей при открытии страницы.
